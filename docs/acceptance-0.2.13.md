## 证据边界

- 120 条独立参考结果没有覆盖三天的最早边界，不能称为三天全部帖子的穷尽对照。
- 故障测试使用真实 X 数据，但在独立测试存储中人为移除一条旧帖、设置三天未检查状态，并禁用一次内容脚本滚动；没有真的等待三天，也没有伪造 X 响应。
- 测试中的 X 限流是真实响应，未缩短其冷却时间。限流期间只能先展示已有未读，不能保证立即获得所有新帖。
- X 搜索不收录的帖子仍可能无法获得。以上验证不等于对 X 全部内容作无遗漏保证。
- 主 Chrome 中原有开发者扩展保持停用，未替换用户数据。
