# X 关注雷达

![只追你关心的，新帖集中看，已读不重复](branding/v1/splash-landscape.png)

把你关心的 X 博主加进名单。面板里直接列出他们最近的推文；有新推文时弹窗告诉你；看过的不再出现。

无需自己申请 X API，也不需要部署服务器。名单、推文缓存和阅读状态只保存在本机浏览器；检查更新时会通过你已登录的 X 网页发起搜索。

## 安装

推荐通过 **Chrome Web Store** 安装，后续版本由 Chrome 自动更新，无需开启开发者模式。

**当前状态：v0.2.5 已提交商店审核，尚未正式上架。** 审核通过后，此处将提供商店直达安装链接。

安装后打开 [X 网页版](https://x.com) 并登录，即可添加博主。需要提前体验或参与开发，可使用下方的[本地安装](#本地安装开发与提前体验)。

## 添加博主

五种方式，任选：

- **推文旁边**：作者和发布时间旁的“＋ 雷达”，直接订阅并打开未读列表；已订阅时显示“查看雷达”，点它即可进入列表。
- **博主主页**：关注按钮旁边的“＋ 雷达”
- **悬停卡片**：鼠标停在任意账号的头像或名字上，卡片里有“＋ 雷达”
- **右键**：在博主的名字、头像或推文链接上点右键 → “添加到 X 关注雷达”
- **面板**：点右下角蓝色圆形按钮 → “博主” → 输入 `@名字` 或主页链接

添加后几秒内，插件会单独查一次这位博主，把他最近的 10 条推文放进“未读”。

再点一次“✓ 已在雷达”即可移除。

## 面板

点右下角蓝色圆形按钮，或工具栏上的插件图标。
每次重新打开都会回到“未读”，按从新到旧排列，上次看过的不会再出现。

打开面板会立即逐个检查所有订阅博主，不受定时检查间隔限制。先显示本地未读，检查结果到达后自动补入列表，多位博主的帖子统一按发布时间排序。漏抓后补回的近期帖子，只要尚未看过，也会进入未读；不会因为发布时间早于订阅日期就直接当成已读。

- **未读**：名单里所有博主的推文混在一起，从新到旧排。正文、配图、引用的推文都直接显示，长文可以点“展开”。
  点卡片在新标签页打开原推文，点 ✓ 直接标为已读，“全部已读”一次清空。
- **全部**：最近 300 条记录，看过的也在这里。长正文和引用保留全文，可以展开查看。
- **博主**：名单管理和设置（检查间隔、是否弹窗、是否包含转推、可选的 X 列表链接）。

按钮和工具栏图标上的数字是未读数。

## 不重复的规则

**弹窗**：每条推文只弹一次。

**未读列表**：一条推文看过就不再出现。下面几种都算看过：

- 在面板里露出大半并停留约 1.5 秒
- 点开过，或点了 ✓、“全部已读”
- 在 X 的首页或任何时间线上刷到过（露出一半以上并停留约 1 秒）

正在看的时候卡片不会消失，只是标上“已看”；关掉面板，下次打开就不在未读里了。想回头找，去“全部”。
同一串连续推文逐条展示、逐条判定已读，不会因为读了第一条就把后续帖子一起隐藏。后台标签页不计为阅读。

**刚订阅的博主**：最近 10 条进未读，但不弹窗。只有订阅之后发的才算新推文，才会弹窗。

**取消订阅再加回来**：没看过的最近推文回到未读，看过的不回来。

**转推**：默认不算更新，可在设置里打开；同一条被多位博主转推只算一条。

## 它怎么拿到推文

你打开 X 时（以及之后每隔 30 分钟，可调），插件在后台开一个不激活的标签页，加载 X 的搜索页，读到数据后立刻关掉：

```
(from:博主A OR from:博主B …) -filter:replies -filter:nativeretweets
```

也就是这些博主本人发的推文，不要回复，不要转帖。每 10 位博主合成一次搜索，依次进行；
新订阅的博主第一次单独搜索，免得被发帖多的博主挤掉。

这和你自己打开搜索页是一回事，只是由插件代劳。插件只读，不发帖、不点赞、不关注。

## 更新失败时

X 临时加载失败或超时时，扩展会自动重新打开当前后台页重试一次。连续失败会保留缓存和已读记录，并显示“更新失败，当前为缓存”及上次成功更新时间；此时不能把列表中的第一条当作 X 的最新帖子。可点击“检查”手动重试，或等待下一次定时检查。

## 局限

- 只在你打开 X 网页版时工作，手机 App 管不到
- 每次搜索只读最新的约 20 条；离开很久再回来，更早的可能读不到
- 打开面板时，每位博主最多补回近期 10 条未看过的旧帖；无法保证补齐全部历史。订阅较多时会依次检查，更新需要更久。
- 依赖 X 的页面和数据结构，X 改版后可能需要跟着修
- X 的搜索偶尔不收录个别账号。遇到这种情况，可把这些账号放进一个 X 列表，把列表链接填到设置里
- “不要转帖”这个搜索条件如果 X 不认，插件会发现（新博主第一次一条都查不到），自动改用不带它的搜索；
  这时后台搜索页上能看到转帖，但插件不会收录它们
- X 正在小范围测试一套新的页面结构（未登录时能看到）。如果登录版也换过去，“＋ 雷达”按钮和“时间线上刷到过算看过”
  需要跟着更新；检查本身读的是 X 自己的数据，不受页面结构影响

## 本地安装（开发与提前体验）

1. 从 [Releases](https://github.com/Talljack/x-follow-radar/releases/latest) 下载 `x-follow-radar-版本号.zip`，解压到固定目录；开发者也可克隆本仓库。
2. 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 打开已登录的 X 网页。如页面仍显示旧版控件，请刷新页面。

本地安装需要保持开发者模式开启，并保留解压目录。

### 更新本地版本

将新版文件更新到原目录后，打开 `chrome://extensions`，点击“X 关注雷达”卡片上的刷新按钮。名单和阅读记录会保留；如已打开的 X 页面仍显示旧版控件，请刷新页面。

面板“博主”页底部可以查看当前版本号。以上手动更新步骤仅适用于本地安装。

## 测试

```
npm ci
npx playwright install chromium
npm test
```

测试会在本机起一个模仿 X 页面结构的假站点，用真实的插件跑完整流程：快速添加、新博主的推文进未读、
进入 X 自动检查、弹窗、不重复、面板里看过即去重、首页看过的不再提醒、取消订阅再加回来、
读页面卡片兜底、未登录提示、插件更新后页面不用刷新、定时检查。截图在 `test/shots/`。

## 商店素材

`store/listing.json` 包含上架描述、权限用途和审核说明。`npm run store:screenshots` 使用离线模拟站点和真实扩展生成 1280×800 功能截图，所有帖子均为明确标记的演示内容。

## 打包

运行 `npm run package`，产物位于 `dist/x-follow-radar-版本号.zip`。包内不包含测试、截图、文档或开发依赖。

## 隐私

详见 [隐私说明](PRIVACY.md)。扩展不包含统计 SDK，不向开发者服务器发送数据，不读取其他网站的浏览记录。

## 目录

- `background.js`：名单、去重账本、检查调度
- `content.js`：面板、弹窗、页面上的添加按钮、“看过”的判定；在后台标签页里负责读时间线
- `hook.js`：只在后台标签页里生效，抄一份 X 自己下载的时间线数据
- `shared.js`：账号名解析、推文数据解析
- `tools/package.mjs`：只打包运行必需文件，生成商店 ZIP
- `branding/v2/`：加入 X 标记的正式图标
- `branding/v1/`：原始品牌资产与欢迎宣传图
- `PRIVACY.md`：隐私说明

读推文卡片的选择器参考了 [yetone/rewind-for-x](https://github.com/yetone/rewind-for-x)（MIT）。
